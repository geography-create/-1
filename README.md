# 승기천 정비 시뮬레이터

통합사회1 (Ⅲ. 자연환경과 인간) 수업 "승기천 정비 계획으로 비교하는 인간중심주의와
생태중심주의"에서 사용하는 학생용 웹앱입니다. 학생이 여섯 가지 하천 정비 항목을
직접 조정하며 다섯 개 지표(홍수 안전성·이용 편의성·생태 다양성·수질·경관 자연성)의
변화를 확인하고, 서로 다른 안을 저장·비교한 뒤 선택의 이유를 스펙트럼(인간중심주의
~ 생태중심주의) 위에 놓아보는 4단계(도입-탐색-비교-정리) 활동으로 구성됩니다.

지표 수치는 교육용으로 설계한 가상 모델이며 실제 승기천 정비사업의 예측값이
아닙니다. 로그인이나 개인정보 저장 없이 동작하며, 새로고침하면 그 세션의 기록은
사라집니다.

화면 오른쪽 아래의 "교사용 진행 안내" 버튼을 누르면 차시 흐름과 유의사항을 바로
확인할 수 있습니다.

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드
npm run lint     # oxlint
```
