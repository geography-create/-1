# 한여울시 도시 설계 — 누구의 도시를 만들 것인가

고등학교 **「도시의 미래 탐구」**(2022 개정) 수행평가의 **사전 연습용 웹앱**입니다.

실제 수행평가는 **종이에 칩니다.** 종이에서는 앱이 대신 계산해 주지 않으므로, 학생은
시설을 어디에 놓았을 때 어떤 숫자가 붙는지 직접 더할 수 있어야 합니다. 이 앱은 그 계산을
눈에 익히는 연습장입니다. 그래서 개인정보를 받지 않고, 제출 기능도 없습니다.

- **성취기준** [12도탐04-01] 지속가능성과 회복력이 높은 도시가 되기 위한 요건에 대해
  토의하고 이와 관련한 도시 계획 및 도시 혁신 사례를 탐구한다.
  (연계) [12도탐04-02] 도시의 공공성과 도시에 대한 권리를 이해하고, 시민 참여를 통해
  도시 문제를 해결하는 과정을 탐구한다.
  (연계) [12도탐03-01] 도시의 환경 문제와 재난을 공간 정의의 관점에서 분석하여 해결
  방안을 탐색한다.
- **평가 방법** 서술·논술 + 공간적 의사 결정 활동 + 교사 관찰 및 기록
- **배점** 서술 3문항 × 5점 = 15점
- **AI 활용** 평가 계획서에 따라 **X**. 앱에 AI 기능은 들어 있지 않습니다.

## 화면 흐름

1. **과제 안내** — 계산 규칙과 채점 기준을 처음부터 공개합니다.
2. **배치** — 예산 18 안에서 시설을 놓습니다. 네 생활권의 **계산 과정이 항상 펼쳐져** 있어,
   한 칸 놓을 때마다 어느 줄의 숫자가 바뀌는지 따라갈 수 있습니다.
3. **결과** — 생활권 격차, 3년차 집중호우와 6년차 폭염, 비인간 존재 지표를 봅니다.
4. **안 비교** — 저장해 둔 배치안을 최대 3개까지 나란히 놓고 견줍니다.
5. **서술 연습** — 세 문항을 미리 써 봅니다. 어디로도 전송되지 않습니다.

## 계산 규칙

무작위 요소가 **없습니다.** 같은 배치는 반 전체에서 언제나 같은 결과를 냅니다.
학생이 종이에서 손으로 따라 할 수 있도록 규칙은 **보정 4가지 + 재난 2가지**로 줄였습니다.

| 항목 | 규칙 |
| --- | --- |
| 생활권 지수 | 출발선 보정 + 기존 시가지 + 내가 놓은 시설 + 보정 + 재난 |
| 종합 생활 편익 | 사회 + 경제 + 환경 (가중치 없이 그냥 더합니다) |
| 생활권 격차 | 최고 − 최저. 6 미만 **안정**, 6 이상 **경계**, 10 이상 **위험** |
| 보정 ① | 간선도로가 한 곳도 없는 생활권 → 사회 −1 (교통 소외) |
| 보정 ② | 보건·복지센터도 학교도 없는 생활권 → 사회 −1 (공공서비스 소외) |
| 보정 ③ | 논·습지를 덮은 칸 하나마다 → 환경 −1 |
| 보정 ④ | 주택과 바로 맞닿은 공장·산업단지 하나마다 → 사회 −1 |
| 3년차 집중호우 | 저지대 칸 수 ÷ 4(올림)만큼 물 받이가 없으면 사회 −2, 경제 −2.<br>물 받이 = 녹지 칸 수 + 빗물 저류지(저지대 2, 그 밖 1) + 하수·빗물처리시설 1 |
| 6년차 폭염 | 생활권 녹지가 2칸 미만이면 사회 −1, 환경 −1 |

격차 판정선이 6/10인 것은, 비교 대상인 종합 생활 편익이 세 지수를 더한 값이라 눈금이 세
배이기 때문입니다. 지수 하나로 환산하면 켄텍 문제의 3/5과 같은 뜻입니다.

**비인간 존재**(하천 생태·도시 숲·도시 속 동물)는 녹지 연결성을 따져야 해서 손으로 세기
번거롭습니다. 그래서 앱에서만 점수로 보여 주고, 종이 답안에서는 "하천변에 무엇을 놓았나",
"녹지가 이어졌나 끊겼나"를 눈으로 보고 서술하게 했습니다. 채점 기준 ①의 5점도 수치가
아니라 "영향까지 밝힌 경우"이므로 이것으로 충분합니다.

## 출발선은 판 위에 있습니다

생활권마다 **기존 시가지가 미리 깔려** 있고 학생은 이를 지울 수 없습니다. 무엇이 이미
있는지가 곧 출발선의 차이이므로, 학생은 안내문을 뒤질 필요 없이 자기 생활권 칸을 세면
됩니다.

| 생활권 | 이미 있는 것 | 판 위로는 표현 못 하는 사정 |
| --- | --- | --- |
| 가람마루 (북서·구도심) | 노후 주택 4, 근린상가 1 | 사회 +1 — 수십 년 이어진 이웃 관계 |
| 새들녘 (북동·신시가지) | 민간 아파트 1, 간선도로 1 | 사회 −1 — 낮에 비는 베드타운 |
| 돌마루 (남서·공단 배후) | 기존 공장 2, 노후 주택 1 | 사회 −1 — 대기질·소음 민원 |
| 버들숲 (남동·외곽) | 노후 주택 1, 논·습지 7칸 | 환경 +1 — 재두루미가 겨울을 난다 |

**돌마루는 구조적으로 불리하게 설계되어 있습니다.** 공장을 안고 시작하고 저지대가 10칸
입니다. 예산 18로 네 생활권의 최소 요건(도로·공공시설·녹지 2칸·방재)을 모두 채우려면 19가
드니, 학생은 반드시 어딘가를 포기해야 합니다. 격차를 완전히 없애는 것은 불가능하고,
**최하 생활권을 누구로 할지 고르는 것**이 이 과제의 핵심입니다.

수치를 바꾸려면 `src/data/facilities.ts`(시설 비용·효과)와
`src/data/city.ts`(예산·기존 시가지·재난 기준·격차 판정선)만 고치면 됩니다. 채점 기준
문구는 `src/data/rubric.ts`에 있습니다.

## 교사용 진행 안내

배포 주소 뒤에 `?teacher=1`을 붙여 접속하면(예: `https://example.com/?teacher=1`) 화면
오른쪽 아래에 **교사용 진행 안내** 버튼이 나타납니다. 차시 배분, 아무것도 놓지 않았을 때의
출발값, 채점할 때 눈여겨볼 지점, 시설 수치표 전체를 볼 수 있습니다. **학생에게 배포하는
링크에는 이 파라미터를 붙이지 마세요** — 붙이지 않으면 버튼 자체가 보이지 않습니다.

## 개인정보

- 반·번호·이름을 **묻지 않습니다.** 제출 기능도 외부 전송도 없습니다.
- 배치와 서술 연습은 학생 브라우저 안(localStorage)에만 자동 저장됩니다. 새로고침하거나
  브라우저를 닫아도 이어서 할 수 있습니다.
- 공용 기기라면 다음 반이 오기 전 상단 **처음부터 다시**로 지우게 안내하세요.
- 시크릿 모드나 저장소가 차단된 환경에서는 자동 저장이 되지 않습니다.

## 개발

```bash
npm install
npm run dev              # 개발 서버
npm run build            # 프로덕션 빌드
npm run build:standalone # 파일 하나로 된 오프라인 버전 (dist-standalone/index.html)
npm run lint             # oxlint
```

`build:standalone`은 배포 없이 파일 하나로 열어볼 수 있는 버전을 만듭니다. JS·CSS가 전부
`dist-standalone/index.html` 한 파일에 들어가 더블클릭만으로 열립니다. 인터넷이 불안정한
교실에서 USB로 돌리거나 동료 교사에게 미리보기를 보낼 때 씁니다. 이 앱은 외부로 아무것도
보내지 않으므로 오프라인에서도 기능이 온전합니다.

## 배포

이 저장소의 GitHub Pages 워크플로(`.github/workflows/deploy-pages.yml`)는 기본 브랜치
(`claude/lesson-plan-webapp-q6trca`, 승기천 정비 시뮬레이터)를 배포하도록 되어 있습니다.
저장소 하나에 Pages 사이트는 하나뿐이라 이 앱을 같은 주소로 올리면 승기천 앱이 덮어
쓰입니다. 이 앱을 Pages로 올리려면 워크플로의 `branches:` 한 줄을 이 브랜치 이름으로
바꾸거나, 위의 `build:standalone`으로 만든 단일 파일을 쓰세요.
