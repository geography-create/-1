# 승기천 정비 시뮬레이터

통합사회1 (Ⅲ. 자연환경과 인간) 수업 "승기천 정비 계획으로 비교하는 인간중심주의와
생태중심주의"에서 사용하는 학생용 웹앱입니다. 학생이 6x6 격자 위에 고정된 하천을 두고
남은 칸에 예산 안에서 타일(주거지·상업건물·전기시설·도로·텃밭공원·공장)을 배치하며 여섯
개 지표(소음 쾌적성·이용 편의성·생태 다양성·수질·경관 자연성·주민 수용성)의 변화를
확인하고, 서로 다른 안을 저장·비교한 뒤 선택의 이유를 스펙트럼(인간중심주의 ~
생태중심주의) 위에 놓아보는 4단계(도입-탐색-비교-정리) 활동으로 구성됩니다.

지표 수치는 교육용으로 설계한 가상 모델이며 실제 승기천 정비사업의 예측값이
아닙니다. 탐색·비교 단계는 로그인이나 개인정보 없이 진행되고, 새로고침하면 그
세션의 기록은 사라집니다. 정리 단계 마지막에만 반·번호·이름과 한 줄 성찰을 입력하며,
이는 아래 "교사용 대시보드"가 설정된 경우에만 선생님의 구글 시트로 전송됩니다.

배포된 주소 뒤에 `?teacher=1`을 붙여 접속하면 (예: `https://your-site.netlify.app/?teacher=1`)
화면 오른쪽 아래에 "교사용 진행 안내" 버튼이 나타나 차시 흐름과 유의사항을 바로
확인할 수 있습니다. 학생에게 배포하는 링크에는 이 파라미터를 붙이지 마세요 — 버튼
자체가 보이지 않습니다.

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드
npm run lint     # oxlint
```

## 교사용 대시보드 설정 (선택)

정리 화면에서 학생이 "작성 완료"를 누르면, 최종 안의 관점(인간중심주의/균형·조화/
생태중심주의)·한 줄 성찰·칭호·발동한 시너지를 반·번호·이름과 함께 구글 시트에 한
줄씩 기록할 수 있습니다. 별도 서버 없이 구글 계정만으로 설정할 수 있어요.

1. 구글 드라이브에서 새 스프레드시트를 만듭니다 (예: "승기천 시뮬레이터 결과").
2. 메뉴에서 **확장 프로그램 > Apps Script**를 엽니다.
3. 기본으로 열려 있는 코드를 지우고, 이 저장소의
   [`google-apps-script/doPost.js`](./google-apps-script/doPost.js) 내용을 그대로
   붙여넣습니다.
4. 오른쪽 위 **배포 > 새 배포**를 클릭합니다.
   - 유형: **웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
5. 배포 후 발급되는 `.../exec`로 끝나는 URL을 복사합니다.
6. 프로젝트 루트에 `.env.local` 파일을 만들고 아래처럼 붙여넣습니다 (`.env.example`
   참고).

   ```
   VITE_SHEET_WEBHOOK_URL=여기에_복사한_URL
   ```

7. `npm run build`로 다시 빌드해서 배포하면, 그 빌드로 접속한 학생들의 제출 내용이
   같은 시트에 쌓입니다.

**주의할 점**

- 브라우저에서 Apps Script 웹 앱으로 보내는 요청은 CORS 제약 때문에 응답을 직접
  확인할 수 없어요. 그래서 학생 화면에는 "제출을 시도했다"는 안내만 뜨고, 실제
  기록 여부는 선생님이 시트를 열어 확인해야 합니다. 수업 전에 미리 한 번
  테스트해 보는 것을 권장합니다.
- `VITE_SHEET_WEBHOOK_URL`을 설정하지 않으면 제출 기능은 그 기기에서만 완료
  표시가 되고, 시트로는 전송되지 않습니다.
- 이 URL이 설정된 순간부터는 이름 등 개인정보가 외부(구글 시트)로 전송되므로,
  학교의 개인정보 처리 방침에 맞게 사용해 주세요.
